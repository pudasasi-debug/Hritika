# Hritika K Portfolio

Static portfolio website for Hritika K.

## Local Preview

From this folder:

```powershell
python -m http.server 8000
```

Open:

```text
http://localhost:8000
```

## GitHub Pages Deployment

1. Push this folder's contents to the root of `https://github.com/sambriddhi28/HritikaK`.
2. In GitHub, open **Settings > Pages**.
3. Set **Source** to **Deploy from a branch**.
4. Select branch `main` and folder `/root`.
5. Save.

Live URL:

```text
https://sambriddhi28.github.io/HritikaK/
```

## Important

The homepage must be named `index.html`.
